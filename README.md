# ККИ — библиотека разработчика

Статический русскоязычный сайт с конспектами о разработке карточных и настольных игр.

## Сайт
- Главная страница и карта сайта: https://spbrusty.github.io/ccg-items/
- 17 тематических материалов о проектировании ККИ, балансе, дизайне карт, плейтестах, инструментах и публикации.
- Дополнительный материал: [Математика idle-игр](idle-games-math.html).

Материалы по публикациям ShuffleKit — самостоятельные русскоязычные конспекты с практическими выводами и ссылками на оригиналы, а не дословные переводы статей.

## Разработка
Сайт состоит из статических HTML-страниц и общего файла стилей `style.css`. Сборка, JavaScript и сторонние зависимости не нужны.

GitHub Pages настроен на публикацию из ветки `main`.
