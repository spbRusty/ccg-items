# ccg-items

Репозиторий содержит материалы проекта и русскоязычный сайт-конспект о математике idle-игр.

## Сайт

Главная страница — `index.html`. Это статический адаптивный сайт без сборки, зависимостей и JavaScript-фреймворков. В нём собраны в единый материал идеи о:

- росте стоимости и дохода;
- балансировке генераторов и множителей;
- формулах для покупки объектов пачкой;
- цепочках генераторов и производной прогрессии;
- престиже, сбросах и настройке темпа прогресса.

Текст представляет собой переработанный русскоязычный конспект, а не дословный перевод. Ссылки на исходные статьи находятся в конце материала.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки **main**, папка **/(root)**. После сохранения сайт будет доступен по адресу:

https://spbrusty.github.io/ccg-items/

Если GitHub Pages уже настроен для этого репозитория, новый `index.html` будет опубликован автоматически после завершения сборки.

## Добавление новых материалов

Новые статьи можно добавлять в `index.html` как разделы единого текста либо позже вынести в отдельные страницы и связать их с главной навигацией.
